Thank you for installing {{ .Chart.Name }} {{ .Chart.Version }} (app version {{ .Chart.AppVersion }}).

Release "{{ .Release.Name }}" has been deployed to namespace {{ .Release.Namespace }}.

dwpk is a development workspace platform for Kubernetes: a controller manager
reconciling UserSpace/Workspace/WorkspaceImage, an SSH gateway, and a
marketplace web UI, installed together by this release.

Components in this release:
{{- if or (not (hasKey .Values.manager "enabled")) .Values.manager.enabled }}

  - manager  disabled
{{- end }}
{{- if or (not (hasKey .Values.gateway "enabled")) .Values.gateway.enabled }}
  - gateway  ({{ .Values.gateway.replicas }} replica(s)): SSH endpoint into Workspace pods
{{- else }}
  - gateway  disabled
{{- end }}
{{- if or (not (hasKey .Values.ui "enabled")) .Values.ui.enabled }}
  - ui       ({{ .Values.ui.replicas }} replica(s)): marketplace web UI

{{- if or (not (hasKey .Values.crd "enabled")) .Values.crd.enabled }}

Connect over SSH, as <workspace>@<address>:{{ .Values.gateway.service.port }}
{{- if eq .Values.gateway.service.type "LoadBalancer" }}

  Wait for an external address, then connect to it:

  gateway.service.type is {{ .Values.gateway.service.type }}: expose it yourself
  (LoadBalancer, a NodePort, or port-forward) to reach it from outside the cluster.
